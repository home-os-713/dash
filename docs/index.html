Tech Stack

Next.js 16
The main web framework — handles all pages, routing, and server logic in one repo.
Think of it as the skeleton of the app. Written in TypeScript + React.
React
The UI layer. The dashboard is split into reusable components (MortgageCard, BillsList, etc.).
Similar to Android Views/Composables — each section is its own component with local state.
Supabase
Backend-as-a-service. Handles user auth (sign-up, login, email confirmation) and the PostgreSQL database.
Each user's property and bills data lives here. Row-level security ensures users only see their own data.
Vercel
Hosting and deployment. Connected to GitHub — every push to main auto-deploys to production in ~1 min.
No servers to manage. Free Hobby plan on Jaime's account.
GitHub
Version control and collaboration hub. The single source of truth for all code.
Push access = ability to deploy. Repo: github.com/jaimegarciae/homeowner-dashboard

Getting started locally

1. Clone the repo: git clone https://github.com/jaimegarciae/homeowner-dashboard.git
2. Install deps: npm install
3. Create .env.local with Supabase credentials (get from Jaime)
4. Run locally: npm run dev → open http://localhost:3000
5. Push to main → Vercel auto-deploys ✓
